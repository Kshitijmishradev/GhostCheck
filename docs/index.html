CASE 01 · THE HAUNTING

You can't defend what you can't see.

A traditional WAF stands at the door with a list of known bad faces. It never looks inside the house. So it blocks a payload that your parameterised query would have shrugged off — and waves through the one value your code quietly drops into a shell. It is guarding a building it has never entered.

The old ward

Signature matching

Regex lists and CVE patterns judge the request in isolation. They don't know whether your specific login() is vulnerable to this specific input — so they cry wolf, miss the quiet ones, and never explain why.

The medium

Code-aware sight

GhostCheck reads the handler that will run. It asks a sharper question: given this exact function, can this exact input reach something dangerous? A verdict grounded in your code — with the line, and the proof.

THE INVESTIGATION · HOW A SCAN WORKS

Five moves, from cold room to caught ghost.

Point GhostCheck at a repo and it walks the house the way an investigator would — mapping the rooms, reading the walls, following the trail, and forcing the apparition to show itself.

Map the floor plan Discovery

It finds every route in the codebase — Flask & FastAPI decorators, Express routers — and marks each door: its method, its path, and the handler waiting behind it.

Read the walls Extraction

Using tree-sitter, it parses the source to an AST and lifts out the exact handler function — not string-matching, not the whole file. Just the room where it happened.

Follow the cold trail Taint analysis

It tracks request-derived data — query args, path params, the request body — through every variable and string it touches, all the way to a dangerous sink. Known sanitisers break the trail; nothing else does.

Force the manifestation Proof-of-concept

Because it knows the vulnerability class and the parameter that reaches the sink, it writes the payload that would exploit it — a real curl you can run. The ghost, made to appear.

Set the ward Fix & gate

Each finding ships with the fix that banishes it — and a non-zero exit code, so a haunted build never reaches production. --fail-on HIGH and CI does the exorcism for you.

routes/admin.py — the cold trail, traced
@app.route("/ping")
def ping():
    host = request.args.get("host")   # ← the trail begins (tainted)
    cmd  = "ping -c 1 " + host           # ← carried, unbroken
    out  = os.popen(cmd).read()           # ← reaches a shell. caught.
    return out

THE BESTIARY · KNOWN SPECTERS

Five hauntings GhostCheck is trained to catch.

Each one is a real vulnerability class — recognised from the code, proven with an exploit, and banished with a fix. The lore is for fun. The CWE, the payload, and the ward are real.

The Query Wraith

SQL INJECTION · CWE-89 · HIGH

Whispers false clauses into your database's ear, and it obeys as if they were always true.

query = "SELECT * FROM users WHERE id = " + user_id
↯ id = ' OR '1'='1' -- -
Ward — parameterised queries with bound values; never build SQL by concatenation.

The Puppeteer

OS COMMAND INJECTION · CWE-78 · CRITICAL

Seizes your shell and speaks commands in your server's own voice. The most dangerous guest of all.

os.popen("ping -c 1 " + host)
↯ host = 127.0.0.1; cat /etc/passwd
Ward — no shell; pass args as an array to execFile/subprocess.run([...]) and allow-list input.

The Threshold Phantom

PATH TRAVERSAL · CWE-22 · HIGH

Walks through walls to files it was never meant to touch, one ../ at a time.

send_file(UPLOAD_DIR + "/" + name)
↯ name = ../../../../etc/passwd
Ward — reduce to a basename and confirm the resolved path stays inside the intended directory.

The Errand Shade

SSRF · CWE-918 · HIGH

Sends your server on errands to forbidden places — the ones only it can reach from the inside.

requests.get(url)
↯ url = http://169.254.169.254/latest/meta-data/
Ward — allow-list hosts and schemes; reject internal addresses and cloud-metadata endpoints.

The Mimic

REFLECTED XSS · CWE-79 · MEDIUM

Wears a visitor's script like a stolen face, and reflects it onto the next soul who walks in.

return "<h1>Hello " + name + "</h1>"
↯ name = <script>alert(1)</script>
Ward — escape user input before it touches HTML; never build markup by string concatenation.
